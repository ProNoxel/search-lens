# Search Lens

**Search Lens doesn't decide what you should see.  
It helps you understand what you're seeing.**

## About

Search Lens is a browser extension designed to analyze, classify and customize search results.

It does not simply block advertising.

Instead, it gives users control over how search results are presented:

- highlight sponsored results;
- hide selected result categories;
- reduce visual noise;
- explain why a result was classified;
- customize the appearance of search pages.

## Philosophy

### Transparency over blocking

Search engines contain many different types of results:

- organic results;
- sponsored results;
- marketplaces;
- aggregators;
- official websites;
- AI-generated content;
- unknown or suspicious results.

Search Lens aims to make these differences visible.

The user decides what they want to see.

## Goals

### Short term

- Support the first search provider (Yandex);
- Detect sponsored results;
- Create a result classification engine;
- Add visual highlighting modes.

### Long term

- Support multiple search engines;
- Create a universal classification engine;
- Allow community-driven rules;
- Provide transparent explanations for every classification.

## Project Status

Early development.

The project is currently focused on architecture, research and the first prototype.
