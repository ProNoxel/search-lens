# Дорожная карта Search Lens

## Текущий статус

Search Lens находится на этапе формирования основы проекта.

Главная цель текущего этапа — определить философию проекта, архитектуру и создать первый рабочий прототип.

---

# Версия 0.1 — Первый прототип

## Цель

Создать минимальное расширение для браузера, способное анализировать результаты поиска и определять рекламный контент.

## Планируемые возможности

- Основа расширения для браузера;
- Поддержка первого поискового провайдера (Яндекс);
- Базовое обнаружение рекламных результатов;
- Простая система классификации;
- Режим визуального выделения обнаруженной рекламы.

---

# Версия 0.2 — Движок классификации

## Цель

Перейти от простых правил обнаружения к гибкой системе анализа результатов.

## Планируемые возможности

- Движок анализа результатов;
- Система оценки вероятности;
- Несколько методов обнаружения;
- Объяснение причин классификации;
- Режим разработчика для отладки.

---

# Версия 0.3 — Контроль пользователя

## Цель

Предоставить пользователю полный контроль над отображением результатов.

## Планируемые возможности

- Режим выделения;
- Режим уменьшения заметности;
- Режим сворачивания;
- Режим скрытия;
- Пользовательские настройки отображения.

---

# Версия 0.4 — Правила и сообщество

## Цель

Создать гибкую систему, способную развиваться вместе с изменениями поисковых систем.

## Планируемые возможности

- Внешние файлы правил;
- Правила, поддерживаемые сообществом;
- Автоматическое обновление правил;
- Повышенная адаптивность к изменениям поисковых систем.

---

# Версия 0.5 — Несколько поисковых систем

## Цель

Выйти за пределы поддержки одной поисковой системы.

## Планируемые возможности

- Архитектура с поддержкой провайдеров;
- Подключение дополнительных поисковых систем;
- Общий движок классификации результатов.

---

# Долгосрочное видение

Search Lens стремится стать универсальным инструментом для понимания и настройки поисковой выдачи.

Проект должен помочь пользователю ответить на простой вопрос:

"Что я вижу перед собой и почему это показано мне?"
