# Search Lens Roadmap

## Current Status

Search Lens is currently in the foundation stage.

The main goal of this stage is to define the project philosophy, architecture and create the first working prototype.

---

# Version 0.1 — First Prototype

## Goal

Create a minimal browser extension that can analyze search results and identify sponsored content.

## Planned features

- Browser extension foundation;
- First search provider support (Yandex);
- Basic result detection;
- Simple classification logic;
- Highlight mode for detected sponsored results.

---

# Version 0.2 — Classification Engine

## Goal

Move from simple detection rules to a flexible classification system.

## Planned features

- Result analysis engine;
- Scoring system;
- Multiple detection methods;
- Explanation of classification decisions;
- Developer/debug mode.

---

# Version 0.3 — User Control

## Goal

Give users full control over how results are displayed.

## Planned features

- Highlight mode;
- Fade mode;
- Collapse mode;
- Hide mode;
- Custom display preferences.

---

# Version 0.4 — Rules and Community

## Goal

Create a flexible system that can evolve with search engine changes.

## Planned features

- External rule files;
- Community-maintained rules;
- Automatic rule updates;
- Better adaptability to search engine changes.

---

# Version 0.5 — Multiple Search Providers

## Goal

Expand beyond a single search engine.

## Planned features

- Provider-based architecture;
- Additional search engines support;
- Shared classification engine.

---

# Long-Term Vision

Search Lens aims to become a universal tool for understanding and customizing search results.

The project should help users answer a simple question:

"What am I looking at, and why is it shown to me?"
