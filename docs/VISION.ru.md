# Search Lens Vision

## Почему существует Search Lens

Поисковые системы стали одним из главных инструментов получения информации.

Однако современная поисковая выдача содержит множество различных типов результатов:

- органические результаты;
- рекламные предложения;
- партнёрские материалы;
- маркетплейсы;
- агрегаторы;
- автоматизированный контент.

Часто пользователь видит смешанную выдачу, но не всегда понимает, почему именно эти результаты находятся перед ним.

Search Lens создан для того, чтобы сделать поисковую выдачу более прозрачной.

---

## Главный принцип

**Search Lens не решает, что пользователь должен видеть.  
Он помогает пользователю понять, что он видит.**

Проект не стремится навязать единственный правильный способ просмотра поиска.

Пользователь сам выбирает:

- оставить всё как есть;
- выделить определённые типы результатов;
- скрыть отдельные категории;
- изменить визуальное представление выдачи.

---

## Чем Search Lens отличается

Традиционные блокировщики работают по принципу:

> Найти рекламу → удалить рекламу.

Search Lens работает иначе:

> Проанализировать результат → определить тип → дать пользователю выбор.

Удаление рекламы является только одной из возможностей, а не основной целью.

---

## Принципы проекта

### 1. Прозрачность

Каждая классификация должна иметь понятное объяснение.

Пользователь должен понимать:

- почему результат был отмечен;
- какие признаки были обнаружены;
- насколько уверенно система определила тип результата.

---

### 2. Контроль пользователя

Search Lens не должен принимать решения вместо пользователя.

Настройки отображения принадлежат пользователю.

---

### 3. Минимальное вмешательство

Проект должен изменять только представление информации, а не нарушать работу сайтов.

---

### 4. Открытость

Правила классификации должны быть понятными и расширяемыми.

Сообщество должно иметь возможность улучшать систему.

---

## Будущее проекта

Search Lens начинается как инструмент анализа поисковой выдачи Яндекса.

В будущем проект может стать универсальным движком анализа результатов для различных поисковых систем.
