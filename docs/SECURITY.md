# Security Policy

## Overview

Security and user privacy are important principles of Search Lens.

The project is designed around transparency, minimal intervention and user control.

Search Lens should help users understand search results without collecting unnecessary information or interfering with normal website operation.

---

# Supported Versions

During early development, the latest available version of Search Lens is considered the supported version.

As the project grows, supported versions and maintenance periods may be defined separately.

---

# Reporting Security Issues

If you discover a security vulnerability, please report it privately before making the information public.

A security report should include:

- a description of the issue;
- steps to reproduce the problem;
- affected version;
- possible impact;
- any additional information that may help investigation.

---

# Responsible Disclosure

Security researchers and contributors are encouraged to:

- provide enough information to reproduce an issue;
- avoid accessing or modifying other users' data;
- avoid actions that may harm users or services;
- allow reasonable time for investigation and fixes.

---

# Privacy Principles

Search Lens follows these principles:

## Minimal data collection

Search Lens should not collect unnecessary user information.

---

## User awareness

Users should understand what the extension does and why.

---

## Local processing when possible

Analysis should be performed locally whenever possible.

User data should not leave the device unless there is a clear reason and user awareness.

---

## Transparency

The project should clearly document:

- what data is processed;
- how it is used;
- what permissions are required.

---

# Extension Permissions

Search Lens should request only the permissions required for its functionality.

Every permission should have a clear explanation.

---

# Security by Design

Security considerations should be included during development:

- avoid unnecessary dependencies;
- review third-party code;
- keep dependencies updated;
- validate external input;
- prevent unintended data exposure.

---

# Final Principle

Search Lens should respect the user it is designed to help.

A tool that gives users control must also protect their privacy and security.
