# Search Lens Vision

## Why Search Lens Exists

Search engines have become one of the main tools people use to find information.

However, modern search results contain many different types of content:

- organic results;
- sponsored results;
- partner content;
- marketplaces;
- aggregators;
- automated or AI-generated content.

Users often see a mixed search page without a clear understanding of why certain results appear and how they are ranked.

Search Lens was created to make search results more transparent and understandable.

---

## Core Principle

**Search Lens does not decide what users should see.  
It helps users understand what they are seeing.**

The project does not aim to enforce a single "correct" way of viewing search results.

Users decide how they want to interact with search:

- keep the original appearance;
- highlight specific types of results;
- hide selected categories;
- customize the visual presentation.

---

## How Search Lens Is Different

Traditional ad blockers usually work like this:

> Find advertising → Remove advertising.

Search Lens takes a different approach:

> Analyze a result → Determine its type → Give users control.

Removing advertising is only one possible feature, not the primary purpose of the project.

---

## Project Principles

### 1. Transparency

Every classification should have an understandable explanation.

Users should be able to understand:

- why a result was marked;
- what signals were detected;
- how confident the system is in its classification.

---

### 2. User Control

Search Lens should not make decisions on behalf of users.

The user controls how different types of results are displayed.

---

### 3. Minimal Intervention

The project should modify only the presentation of information, without interfering with the normal operation of websites.

---

### 4. Openness

Classification rules should be understandable, extendable and community-driven.

Everyone should have the opportunity to improve the system.

---

## Future Vision

Search Lens starts as a tool for analyzing search results on Yandex.

In the future, the project may become a universal result analysis engine supporting multiple search platforms.
