# Search Lens

**Search Lens не решает, что вы должны видеть.  
Он помогает понять, что вы видите.**

## О проекте

Search Lens — это расширение для браузера, предназначенное для анализа, классификации и настройки отображения результатов поиска.

Это не просто блокировщик рекламы.

Главная цель проекта — дать пользователю контроль над тем, как он воспринимает поисковую выдачу:

- выделять рекламные результаты;
- скрывать выбранные категории результатов;
- уменьшать визуальный шум;
- объяснять, почему результат был классифицирован;
- настраивать внешний вид страниц поиска.

## Философия

### Прозрачность вместо принудительной блокировки

Современная поисковая выдача содержит разные типы результатов:

- органические результаты;
- рекламные результаты;
- маркетплейсы;
- агрегаторы;
- официальные сайты;
- контент, созданный ИИ;
- неизвестные или подозрительные результаты.

Search Lens стремится сделать эти различия понятными.

Пользователь сам решает, что он хочет видеть.

## Цели проекта

### Ближайшие цели

- Поддержка первого поискового провайдера (Яндекс);
- Обнаружение рекламных результатов;
- Создание системы классификации результатов;
- Добавление режимов визуального выделения.

### Долгосрочные цели

- Поддержка нескольких поисковых систем;
- Создание универсального движка классификации;
- Возможность использования правил, созданных сообществом;
- Понятные объяснения для каждой классификации.

## Текущий статус

Ранняя стадия разработки.

Сейчас проект находится на этапе проектирования архитектуры, исследования и создания первого прототипа.
