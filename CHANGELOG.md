# v0.0.1-foundation

## Added

- Initial project documentation structure;
- Project vision;
- Development roadmap;
- System architecture description;
- Contribution guidelines;
- Security policy.

## Project Principles Established

- Transparency over blocking;
- User control over automatic decisions;
- Minimal intervention;
- Modular and extensible architecture.

## Notes

This release represents the foundation stage of Search Lens.

No functional browser extension has been released yet.

The main goal of this stage was to define the project's direction, philosophy and technical foundation.
